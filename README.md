# 🐍- **Python Learning**- Curso + Exercícios

#### 📚 **Esse Repositório**:

> Acompanhamento de Resolução de Exercícios da Disciplina Introdução à Algoritmos e Curso Introdução à Linguagem Python-Teo_me_why

Repositório possui finalidade em alocar a resolução de exercícios na Linguagem Python. Funciona como resolução da listas propostas pela disciplina introdução à Algoritmos utilizando a linguagem Python ofertada pela PUC-MINAS somado a isso, possui separado em pastas, o progresso de aprendizado no curso Introdução à Linguagem Python ofertado pelo Teo Calvo, disponível no youtube *https://www.youtube.com/watch?v=OeKzVjiiRm4&list=PLvlkVRRKOYFSpRkqnR0p2A-eaVlpLnN3D&index=1*

Está separado pelas temáticas dos assuntos, por exemplo: Exercícios Propostos para Condionais, Exercícios propostos para Laços de Repetição e assim sucessivamente,
Sempre com o enunciado + a resolução logo à baixo
